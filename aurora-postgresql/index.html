このページについて

Aurora PostgreSQL の設計・構築・運用で頻繁に使う AWS CLI コマンドと SQL を、利用シーン別に整理したリファレンスです。各コードはそのまま実行できる形で記載しています。右上の「コピー」ボタンでクリップボードに取得できます。

$CLUSTER_ID / $INSTANCE_ID / $PG_HOST などの環境変数（1-1 で設定）、sample で始まる名前、<...> 部分は環境に合わせて置き換えてください。AWS CLI の時刻指定は UTC です。

対象バージョン：Aurora PostgreSQL 16 互換（AWS CLI v2 / psql 16）　最終更新：2026年11月

AWS CLI… DB に接続せず実行（AWS CLI v2） SQL… psql で接続して実行（カタログ・統計ビュー） rds_superuser / 変更系… 特権が必要、または状態を変更する
該当するコマンドが見つかりませんでした。

01構築時のコマンド

ネットワーク（サブネットグループ・SG）→ パラメータグループ → クラスター → インスタンス → DB内のロール・権限の順で作成するのが基本です。クラスターを作っただけでは接続できず、インスタンスの追加が必要です。

1-4. クラスター・インスタンス

クラスターの作成（推奨オプション付き）
AWS CLI
--manage-master-user-password でマスターパスワードを Secrets Manager に自動管理させます。時刻は UTC 指定です（17:00 UTC = 02:00 JST）。
aws rds create-db-cluster \
  --db-cluster-identifier $CLUSTER_ID \
  --engine aurora-postgresql --engine-version 16.4 \
  --master-username $PG_USER --manage-master-user-password \
  --db-subnet-group-name sample-aurora-subnet \
  --vpc-security-group-ids $SG_ID \
  --db-cluster-parameter-group-name sample-aurora-cpg \
  --storage-encrypted --kms-key-id alias/sample-rds-key \
  --backup-retention-period 7 \
  --preferred-backup-window 17:00-18:00 \
  --preferred-maintenance-window sun:18:00-sun:19:00 \
  --enable-cloudwatch-logs-exports postgresql \
  --enable-iam-database-authentication \
  --copy-tags-to-snapshot --deletion-protection \
  --tags Key=Env,Value=prod Key=System,Value=sample

1-5. データベース・ロール・権限

データベースとスキーマの作成
SQL
マスターユーザーは superuser ではなく rds_superuser ロールのメンバーです。所有者用ロールを分けておくと、権限管理と移行が楽になります。
CREATE ROLE sample_owner NOLOGIN;
CREATE DATABASE sample_db OWNER sample_owner
  ENCODING 'UTF8' LC_COLLATE 'C' LC_CTYPE 'C' TEMPLATE template0;

\c sample_db
CREATE SCHEMA app AUTHORIZATION sample_owner;
REVOKE CREATE ON SCHEMA public FROM PUBLIC;          -- public スキーマへの作成を禁止
REVOKE ALL ON DATABASE sample_db FROM PUBLIC;
アクセスロール（RO / RW）とログインユーザー
SQL
権限はグループロール（NOLOGIN）に付け、ログインユーザーはそのメンバーにします。
CREATE ROLE sample_ro NOLOGIN;
CREATE ROLE sample_rw NOLOGIN IN ROLE sample_ro;      -- RW は RO を包含

GRANT CONNECT ON DATABASE sample_db TO sample_ro;
GRANT USAGE  ON SCHEMA app TO sample_ro;
GRANT SELECT ON ALL TABLES IN SCHEMA app TO sample_ro;
GRANT SELECT ON ALL SEQUENCES IN SCHEMA app TO sample_ro;
GRANT INSERT, UPDATE, DELETE, TRUNCATE ON ALL TABLES IN SCHEMA app TO sample_rw;
GRANT USAGE ON ALL SEQUENCES IN SCHEMA app TO sample_rw;

CREATE ROLE app_user   LOGIN PASSWORD '<パスワード>' IN ROLE sample_rw CONNECTION LIMIT 200;
CREATE ROLE report_user LOGIN PASSWORD '<パスワード>' IN ROLE sample_ro;
今後作成されるオブジェクトへの既定権限
SQL
ALTER DEFAULT PRIVILEGES は FOR ROLE に指定したロールが作成したオブジェクトにだけ効きます。
ALTER DEFAULT PRIVILEGES FOR ROLE sample_owner IN SCHEMA app
  GRANT SELECT ON TABLES TO sample_ro;
ALTER DEFAULT PRIVILEGES FOR ROLE sample_owner IN SCHEMA app
  GRANT INSERT, UPDATE, DELETE, TRUNCATE ON TABLES TO sample_rw;
ALTER DEFAULT PRIVILEGES FOR ROLE sample_owner IN SCHEMA app
  GRANT USAGE ON SEQUENCES TO sample_rw;
IAM 認証ユーザー
SQLAWS CLI
クラスターで IAM 認証を有効にしたうえで、DB ユーザーに rds_iam を付与します。トークンの有効期間は15分です。
CREATE ROLE iam_user LOGIN;
GRANT rds_iam TO iam_user;
GRANT sample_ro TO iam_user;

# 接続（シェル側）
export PGPASSWORD=$(aws rds generate-db-auth-token --hostname $PG_HOST --port 5432 --username iam_user)
psql "host=$PG_HOST dbname=sample_db user=iam_user sslmode=require"
拡張機能の導入
SQL
pg_stat_statements / pgaudit / pg_cron は shared_preload_libraries への追加と再起動が先に必要です。
SELECT name, default_version, installed_version FROM pg_available_extensions ORDER BY name;

CREATE EXTENSION IF NOT EXISTS pg_stat_statements;
CREATE EXTENSION IF NOT EXISTS pgaudit;
CREATE EXTENSION IF NOT EXISTS pgstattuple;
\c postgres
CREATE EXTENSION IF NOT EXISTS pg_cron;   -- pg_cron は cron.database_name の DB（既定 postgres）に作成
注意：ALTER DEFAULT PRIVILEGES はFOR ROLE に指定したロールが作成したオブジェクトにだけ適用されます。マスターユーザーなど別のロールで CREATE TABLE すると権限が付かないため、DDL は所有者ロール（SET ROLE sample_owner）で実行してください。

1-6. 接続設定

psql 接続（SSL 証明書検証あり）
psql
証明書バンドルは https://truststore.pki.rds.amazonaws.com/global/global-bundle.pem から取得します。更新系はクラスターエンドポイント、参照系はリーダーエンドポイント（cluster-ro-）に接続します。
psql "host=$PG_HOST port=5432 dbname=$PG_DB user=$PG_USER sslmode=verify-full sslrootcert=global-bundle.pem"

# 非対話実行・CSV 出力
psql -h $PG_HOST -U $PG_USER -d $PG_DB --csv -c "SELECT now();"
psql -h $PG_HOST -U $PG_USER -d $PG_DB -v ON_ERROR_STOP=1 -f deploy.sql -o result.txt
~/.pgpass と ~/.psqlrc
psql
パスワード入力の省略と、調査向けの表示設定です。.pgpass は権限 600 にしないと無視されます。
# ~/.pgpass   host:port:database:user:password
sample-aurora-cluster.cluster-xxxxxxxx.ap-northeast-1.rds.amazonaws.com:5432:*:postgres:<パスワード>
chmod 600 ~/.pgpass

# ~/.psqlrc
\set ON_ERROR_STOP on
\timing on
\x auto
\set PROMPT1 '%M %n@%/%R%# '

2-4. テーブル・カラム定義書の作成

データベースの文字コード・照合順序・所有者
SQL
SELECT datname, pg_get_userbyid(datdba) AS owner, pg_encoding_to_char(encoding) AS encoding,
       datcollate, datctype, datconnlimit,
       pg_size_pretty(pg_database_size(datname)) AS size
FROM pg_database WHERE NOT datistemplate ORDER BY pg_database_size(datname) DESC;
テーブル一覧（行数・サイズ・コメント付き）
SQL
SELECT n.nspname AS schema, c.relname AS table,
       CASE c.relkind WHEN 'r' THEN 'table' WHEN 'p' THEN 'partitioned' WHEN 'm' THEN 'matview' END AS kind,
       c.reltuples::bigint AS est_rows,
       pg_size_pretty(pg_total_relation_size(c.oid)) AS total_size,
       obj_description(c.oid, 'pg_class') AS comment
FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r', 'p', 'm') AND n.nspname NOT IN ('pg_catalog', 'information_schema')
  AND n.nspname NOT LIKE 'pg_toast%'
ORDER BY pg_total_relation_size(c.oid) DESC;
カラム定義一覧（型・NULL 可否・デフォルト・コメント）
SQL
SELECT c.table_schema, c.table_name, c.ordinal_position, c.column_name,
       c.data_type, c.character_maximum_length, c.numeric_precision, c.numeric_scale,
       c.is_nullable, c.column_default,
       col_description(format('%I.%I', c.table_schema, c.table_name)::regclass, c.ordinal_position) AS comment
FROM information_schema.columns c
WHERE c.table_schema NOT IN ('pg_catalog', 'information_schema')
ORDER BY c.table_schema, c.table_name, c.ordinal_position;
制約・インデックス・パーティション
SQL
-- 主キー・外部キー・一意制約・CHECK 制約
SELECT conrelid::regclass AS table, conname, contype, pg_get_constraintdef(oid) AS definition
FROM pg_constraint
WHERE connamespace::regnamespace::text NOT IN ('pg_catalog', 'information_schema')
ORDER BY 1, 3;

-- インデックス定義
SELECT schemaname, tablename, indexname, indexdef FROM pg_indexes
WHERE schemaname NOT IN ('pg_catalog', 'information_schema') ORDER BY 1, 2;

-- パーティション構成
SELECT parent.relname AS parent, child.relname AS partition,
       pg_get_expr(child.relpartbound, child.oid) AS bound
FROM pg_inherits i
JOIN pg_class parent ON parent.oid = i.inhparent
JOIN pg_class child  ON child.oid  = i.inhrelid
WHERE parent.relkind = 'p' ORDER BY 1, 2;
主キーのないテーブル
SQL移行前チェック
論理レプリケーションや AWS DMS では、主キー（または REPLICA IDENTITY）がないと UPDATE / DELETE を連携できません。
SELECT c.oid::regclass AS table
FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r', 'p') AND n.nspname NOT IN ('pg_catalog', 'information_schema')
  AND NOT EXISTS (SELECT 1 FROM pg_constraint p WHERE p.conrelid = c.oid AND p.contype = 'p');
オブジェクト棚卸し（スキーマ別の件数）
SQL移行前後の突合せ
SELECT n.nspname AS schema,
       CASE c.relkind WHEN 'r' THEN 'table' WHEN 'p' THEN 'partitioned' WHEN 'i' THEN 'index'
                      WHEN 'S' THEN 'sequence' WHEN 'v' THEN 'view' WHEN 'm' THEN 'matview'
                      WHEN 'f' THEN 'foreign' ELSE c.relkind::text END AS kind,
       count(*)
FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname NOT IN ('pg_catalog', 'information_schema') AND n.nspname NOT LIKE 'pg_toast%'
GROUP BY 1, 2 ORDER BY 1, 2;

-- 関数・プロシージャ・トリガー
SELECT n.nspname, p.prokind, count(*) FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace
WHERE n.nspname NOT IN ('pg_catalog', 'information_schema') GROUP BY 1, 2 ORDER BY 1, 2;
SELECT event_object_schema, event_object_table, trigger_name, action_timing, event_manipulation
FROM information_schema.triggers ORDER BY 1, 2;
シーケンスの使用率（枯渇の確認）
SQL
SELECT schemaname, sequencename, data_type, last_value, max_value,
       round(100.0 * last_value / max_value, 2) AS used_pct
FROM pg_sequences ORDER BY used_pct DESC NULLS LAST;

2-5. 権限構成の取得

ロール一覧と属性
SQL
SELECT rolname, rolcanlogin, rolsuper, rolcreaterole, rolcreatedb,
       rolconnlimit, rolvaliduntil
FROM pg_roles WHERE rolname NOT LIKE 'pg\_%' ORDER BY rolname;
ロールのメンバーシップ（親子関係）
SQL
SELECT r.rolname AS role, m.rolname AS member, am.admin_option
FROM pg_auth_members am
JOIN pg_roles r ON r.oid = am.roleid
JOIN pg_roles m ON m.oid = am.member
ORDER BY 1, 2;
テーブル権限と既定権限
SQL

3-1. クエリ実行状況

累計実行時間の長い SQL TOP 20
SQLpg_stat_statements
統計は前回リセット（またはインスタンス再起動）からの累計です。
SELECT queryid, calls,
       round(total_exec_time::numeric / 1000, 1) AS total_sec,
       round(mean_exec_time::numeric, 1)        AS mean_ms,
       round(stddev_exec_time::numeric, 1)      AS stddev_ms,
       rows,
       round(100.0 * shared_blks_hit / nullif(shared_blks_hit + shared_blks_read, 0), 1) AS hit_pct,
       left(query, 120) AS query
FROM pg_stat_statements
ORDER BY total_exec_time DESC LIMIT 20;
1回あたりが遅い SQL／一時ファイルを使う SQL
SQLpg_stat_statements
-- 平均実行時間の長い SQL（実行回数 10 回以上）
SELECT calls, round(mean_exec_time::numeric, 1) AS mean_ms, left(query, 120)
FROM pg_stat_statements WHERE calls >= 10
ORDER BY mean_exec_time DESC LIMIT 20;

-- 一時ファイル（ディスクへの書き出し）が多い SQL：work_mem 不足の兆候

FROM pg_stat_statements WHERE temp_blks_written > 0
ORDER BY temp_blks_written DESC LIMIT 20;

長期間アクセスされていないテーブル
SQL

SELECT relname, seq_scan, idx_scan, n_tup_ins, n_tup_upd, n_tup_del,
       pg_size_pretty(pg_total_relation_size(relid)) AS size
FROM pg_stat_user_tables
WHERE coalesce(seq_scan, 0) + coalesce(idx_scan, 0) = 0
  AND n_tup_ins + n_tup_upd + n_tup_del = 0
ORDER BY pg_total_relation_size(relid) DESC;

日次ヘルスチェック（1本の SQL で要点を確認）
SQL
SELECT
  (SELECT count(*) FROM pg_stat_activity)                                         AS connections,
  (SELECT count(*) FROM pg_stat_activity WHERE state = 'idle in transaction')    AS idle_in_tx,
  (SELECT max(now() - xact_start) FROM pg_stat_activity)                          AS oldest_xact,
  (SELECT max(age(datfrozenxid)) FROM pg_database)                                AS max_xid_age,
  (SELECT count(*) FROM pg_replication_slots WHERE NOT active)                    AS inactive_slots,
  (SELECT round(100.0 * sum(blks_hit) / nullif(sum(blks_hit + blks_read), 0), 2)
     FROM pg_stat_database)                                                       AS cache_hit_pct;
