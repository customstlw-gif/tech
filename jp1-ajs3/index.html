このページについて

JP1/AJS3 - Manager / Agent Version 13 for Linux の構築・運用で使うコマンドを、利用シーン別に整理したリファレンスです。右上の「コピー」ボタンでクリップボードに取得できます。

'<...>' 部分と、例として記載したホスト名・IPアドレス・パスは環境に合わせて置き換えてください。

対象バージョン：JP1/AJS3 - Manager / Agent Version 13 for Linux ／ 最終更新：2026年11月

root… root権限（sudo）が必要 pkg… 追加パッケージ・前提製品が必要な場合あり 注意… サービス影響・設定変更あり

01構築時のコマンド

JP1/Base → JP1/AJS3 の順にセットアップします。コマンドは UNIX版の既定パス(/opt/jp1base/bin、/opt/jp1ajs2/bin)にあります。

1-1. 起動・停止

JP1/Baseを起動
root
/etc/opt/jp1base/jbs_start
JP1/AJS3を起動
root
/etc/opt/jp1ajs2/jajs_start
JP1/AJS3を停止
root注意
/etc/opt/jp1ajs2/jajs_stop
JP1/Baseを停止(AJS3停止後に実施)
root注意
/etc/opt/jp1base/jbs_stop
JP1/Baseのプロセス状態
root
jbs_spmd_status
JP1/AJS3のプロセス状態
root
jajs_spmd_status

1-2. JP1ユーザー・ユーザーマッピング(JP1/Base)

JP1ユーザーを登録(認証サーバーで実施)
root
jbsadduser <JP1ユーザー名>
権限設定(ACL)を反映
root
jbsaclreload
JP1ユーザーとOSユーザーを対応付け(ジョブ実行ユーザー)
root
jbsmkumap -u <JP1ユーザー名> -o <OSユーザー名> -s "*"
ユーザーマッピングを確認
root
jbsgetumap

1-3. スケジューラーサービス・環境設定

スケジューラーサービスを追加(複数サービス運用時。指定オプションはマニュアル参照)
root注意
jajs_setup -a -F AJSROOT2 <オプション>
環境設定パラメーターを変更
root注意
jajs_config -k "[JP1_DEFAULT\JP1AJSMANAGER\AJSROOT1]" "環境設定パラメーター名"=dword:<値>
定義ファイルの内容を共通定義情報に反映
root注意
jbssetcnf <定義ファイル>

1-4. ジョブ定義の登録・実行

定義ファイル(ajsprint形式)からユニットを一括定義
ajsdefine -F AJSROOT1 <定義ファイル> /<ジョブグループ>
ジョブネットを計画実行登録
ajsentry -F AJSROOT1 /<グループ>/<ジョブネット>
ジョブネットを即時実行登録(テスト実行)
注意
ajsentry -F AJSROOT1 -n /<グループ>/<ジョブネット>
実行登録を解除
注意
ajsleave -F AJSROOT1 /<グループ>/<ジョブネット>

02構築完了後の構成情報の取得

ジョブ定義・環境設定・エージェント定義を出力し、パラメータシートと突き合わせます。ajsprint の出力は ajsdefine でそのまま再登録できます。

2-1. 環境設定

共通定義情報(JP1/Base・AJS3の環境設定パラメーター)を全出力

jbsgetcnf > /tmp/jp1_conf.txt
稼働情報と有効な環境設定パラメーター
jajs_status
スケジューラーサービスと組み込みDBの対応
root
ajsembdbidlist
JP1/AJS3 - Manager のバージョン情報
root
ajsembdbstatus -c
JP1製品のインストール状況
rpm -qa | grep -i jp1

2-2. ジョブ定義・エージェント

ユニット定義を下位ユニット含め定義ファイル形式で出力
ajsprint -F AJSROOT1 -a -R /<グループ> > /tmp/ajs_def.txt
指定グループ配下のユニット名を表示
ajsname -F AJSROOT1 /<グループ>
実行エージェントの定義一覧
ajsagtshow

2-3. JP1/Base 設定

ユーザーマッピング
root
jbsgetumap
JP1ユーザーの権限設定ファイル
root
ls -l /etc/opt/jp1base/conf/user_acl/

05バックアップ・リストア

ジョブ定義の退避と組み込みDBのバックアップです。定期的に取得し、構成管理(Git等)で差分を管理すると変更履歴を追えます。

5-1. ジョブ定義

全ユニット定義を退避
ajsprint -F AJSROOT1 -a -R / > /backup/ajs_def_$(date +%F).txt
退避した定義を回復
注意
ajsdefine -F AJSROOT1 /backup/ajs_def.txt /<グループ>
退避ボックスへユニットを退避(オプションはマニュアル参照)
ajsbackup -F AJSROOT1 <オプション> /<グループ>/<ジョブネット>
退避ボックスからユニットを回復
注意
ajsrestore -F AJSROOT1 <オプション>
ジョブネットの実行登録状態を退避(移行・再構築時)
ajsrgexport -F AJSROOT1 <オプション>
実行登録状態を回復
注意
ajsrgimport -F AJSROOT1 <オプション>

5-2. 組み込みDB・設定ファイル

組み込みDBのバックアップ(運用方式に応じたオプションはマニュアル参照)
root
ajsembdbbackup <オプション> -id _JF0
設定ファイル一式を退避
root
tar czf /backup/jp1_conf_$(date +%F).tar.gz /etc/opt/jp1base /etc/opt/jp1ajs2

A構成情報一括取得スクリプト

環境設定パラメーターとジョブ定義を出力し、ホスト単位で保存するスクリプト例です。ジョブ定義(ajsprint 出力)を構成管理(Git 等)に登録すると、ジョブ変更の履歴管理とレビューに使えます。

一括取得スクリプト（例）
bash
#!/bin/bash
# JP1/AJS3 構成情報一括取得スクリプト(root で実行)
export PATH=/opt/jp1base/bin:/opt/jp1ajs2/bin:$PATH
SVC=AJSROOT1
OUT=/var/tmp/jp1_evidence_$(hostname -s)_$(date +%Y%m%d_%H%M%S)
mkdir -p "$OUT"
run() { echo "### $2" > "$OUT/$1.txt"; eval "$2" >> "$OUT/$1.txt" 2>&1; }
run base_status "jbs_spmd_status"
run ajs_status  "jajs_spmd_status"
run conf        "jbsgetcnf"
run umap        "jbsgetumap"
run jajs_status "jajs_status"
run agents      "ajsagtshow"
run packages    "rpm -qa | grep -i jp1"
ajsprint -F $SVC -a -R / > "$OUT/ajs_definition.txt" 2> "$OUT/ajsprint.err"
tar czf "$OUT.tar.gz" -C "$(dirname "$OUT")" "$(basename "$OUT")"
echo "出力: $OUT.tar.gz"

B利用上の注意

  • <> で囲んだ値は、環境に合わせて置き換えてください。スケジューラーサービス名(AJSROOT1)や組み込みDBのセットアップ識別子(_JF0)は環境に合わせてください。
  • 「注意」が付いたコマンドは、サービス停止・業務影響・データ変更を伴う可能性があります。本番環境では事前に検証環境で確認し、作業手順書に基づいて実施してください。
  • コマンドの格納先は /opt/jp1base/bin、/opt/jp1ajs2/bin です。必要に応じて PATH に追加してください。
  • クラスター構成では -h 論理ホスト名 を指定してコマンドを実行します。
  • 「オプションはマニュアル参照」としたコマンドは、運用方式(バックアップ強化機能の有無など)によって指定内容が変わります。『JP1/AJS3 コマンドリファレンス』で確認してください。
  • ジョブ操作系のコマンド(ajsentry・ajsrerun・ajskill など)は、実行した JP1 ユーザーの権限で動作します。

掲載コマンドは一般的な仕様に基づくサンプルです。バージョンやエディションにより利用できない構文があります。本番環境で実行する前に、検証環境と日立製作所の公式マニュアルで確認してください。
